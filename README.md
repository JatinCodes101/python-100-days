# Day 01: Rollercoaster Eligibility Checker

## Project Overview

A beginner Python program that checks whether a user meets the minimum height requirement to ride a rollercoaster.

## Concepts Learned

- `print()` — Displaying messages
- `input()` — Taking user input
- `int()` — Converting text into an integer
- `if-else` — Making decisions based on conditions
- Comparison operator `>=`
- Indentation and code blocks

## How to Run

Run `rollercoaster.py` using Python and enter your height in centimeters when prompted.

## What I Learned

I learned how Python uses conditional statements to make decisions based on user input.
